# Dockerfiles

## This Repository Contains Dockerfiles for Containerizing Java Web Applications.

## Contents
**Tomcat Web Application: Deploys a Maven Built WAR File on Apache Tomcat 9 With JDK 11.**<br>
**Spring Boot Application: Runs a Spring Boot JAR File Using Eclipse Temurin JDK 8.**<br>
**Multi Stage Docker Build: Builds a Spring Boot Application Using Maven and Packages it into a Separate Runtime Image.**<br>

## Technologies Used
**Docker**<br>
**Java**<br>
**Apache Tomcat**<br>
**Maven**<br>
**Spring Boot**<br>

## This Repository Demonstrates How Docker Can be Used to Containerize Java Web Applications, Deploy Applications on Tomcat and Build Spring Boot Applications Efficiently Using Multi Stage Docker Builds.
